# AI-Powered Blogging Platform

A modern full-stack blogging platform built using the MERN stack with AI-assisted content generation and a responsive user experience.

## 🚀 Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB
- Tailwind CSS
- JWT Authentication

## ✨ Features

- AI-assisted blog generation
- Secure JWT authentication
- Role-based admin dashboard
- Blog and category management
- Image uploads
- Search and filtering
- Responsive user interface
- RESTful APIs
